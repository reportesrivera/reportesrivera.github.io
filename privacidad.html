Política de privacidad — Reportes Rivera

Reportes Rivera es una herramienta interna de un único usuario (el propietario de los canales) para consultar las estadísticas de sus propios canales de YouTube mediante las API oficiales de Google/YouTube (YouTube Data API v3 y YouTube Analytics API), con permisos exclusivamente de lectura.

  • Datos a los que se accede: métricas y metadatos de los canales autorizados por el propio propietario (vistas, tiempo de visualización, retención, suscriptores, títulos y comentarios de sus propios videos).
  • Uso: elaborar reportes internos de rendimiento para el propietario. Nada más.
  • No se comparte, vende ni cede ningún dato a terceros.
  • No se modifica ni publica contenido en YouTube desde esta aplicación.
  • Conservación: los datos de API se renuevan y eliminan conforme a las políticas de YouTube (nunca se conservan más de 30 días sin renovarse).
  • Revocación: el propietario puede revocar el acceso en cualquier momento desde https://myaccount.google.com/permissions
  • Contacto: el propio propietario de los canales, lecrivere@gmail.com
