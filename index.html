Reportes Rivera

Reportes Rivera es una herramienta personal de un único usuario (el propietario de los canales) para consultar, en modo de solo lectura, las métricas de sus propios canales de YouTube mediante las API oficiales de Google: YouTube Data API v3 y YouTube Analytics API.

La aplicación no publica ni modifica contenido en YouTube y no comparte datos con terceros. Su único uso es elaborar reportes internos de rendimiento para el propietario.
